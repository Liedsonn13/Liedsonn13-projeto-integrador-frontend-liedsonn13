
O GameVault é um catálogo de jogos criado para apresentar diferentes títulos de forma simples e organizada.
O projeto reunirá informações como nome, gênero, plataforma e descrição dos jogos.
A proposta é facilitar a busca e a descoberta de jogos para diferentes tipos de jogadores.
Durante a disciplina, o projeto será desenvolvido e receberá novas funcionalidades.
